# Template de proiect – Programare Web / Dezvoltarea Aplicațiilor Web
### Branch dumitrascu.bogdan

Proiect de pornire pentru laborator, format din două aplicații separate, care comunică prin API:

- **backend** – PHP Symfony, cu bază de date PostgreSQL;
- **frontend** – React.

Totul rulează în containere Docker; nu este nevoie să instalați PHP, Node.js sau PostgreSQL pe calculator.

## Îndrumarul de laborator

Tot ce aveți nevoie (obiectivul disciplinei, programele de instalat, configurarea proiectului, modul de lucru cu Git, baza de date, API-ul și explicarea fiecărui fișier din proiect) se află într-un singur document:

**[Ghid-DAW.pdf](Ghid-DAW.pdf)**

Deschideți-l și parcurgeți-l de sus în jos. Pentru a-l salva pe calculator, apăsați butonul **Download** din dreapta sus, pe pagina fișierului.
